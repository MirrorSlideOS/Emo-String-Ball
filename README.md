# SHOCKOS // Emotional Stringball Arcade

QPOP.EXE interactive fiction browser game. Explore nine timeline routes, five emotional threads, rotating challenges and collectible sparks. Stardust is fictional score only.

| Line | Atmosphere | Color |
|---|---|---|
| 1 | Glee | Yellow |
| 2 | Awe | Violet |
| 3 | Fear | Red |
| 4 | Sadness | Blue |
| 5 | Calm | Green |

## Run locally

Run `python -m http.server 8000` in this repository and open http://localhost:8000.

## Deploy

In GitHub, open Settings → Pages → Build and deployment, select Deploy from a branch, then main and /(root). Save. The site uses static HTML, CSS and JavaScript and needs no build step.

Game progress is stored locally in the browser. No real-money wagering or cashout.
